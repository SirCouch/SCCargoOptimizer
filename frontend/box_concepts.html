Modern theme — box texture concepts

Five replacements for the current dev-texture crates. Every concept uses the item's priority color as the primary color of the box, draws all six faces from the same panel (no more orange sides / gray tops), and sizes every element from the face dimensions, so nothing overlaps from the 1 SCU cube up to the 8-cell-long faces of a 32 SCU crate. Hover a box to rotate it. Reply with a concept letter to have it implemented in the viewer.

Textures are drawn with the same canvas-texture pipeline viewer.html uses (modernFaceTex), at the real per-cell resolution, so what you see here is what the 3D viewer will render. The 8-Bit theme is unaffected.
